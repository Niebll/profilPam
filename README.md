# Tugas Praktikum Pengembangan Aplikasi Mobile (PAM)

Berikut adalah informasi lokasi berkas pengerjaan tugas praktikum:

1. **Tugas Halaman Pemesanan Tiket (Jetpack Compose)**
   - Berkas Kode: [halaman_tiket_screen.kt](app/src/main/java/com/example/anative/tiket/halaman_tiket_screen.kt)
   - Deskripsi: Halaman antarmuka interaktif pemesanan tiket dengan fitur kalkulator total harga, tombol tambah/kurang jumlah tiket, serta tombol reset sesuai spesifikasi desain.

2. **Tugas Pemesanan Tiket - State Hoisting**
   - Berkas Kode: [TiketScreenHoistingState.kt](app/src/main/java/com/example/anative/tiket/TiketScreenHoistingState.kt)
   - Deskripsi: Implementasi halaman pemesanan tiket menggunakan arsitektur State Hoisting. State `hargaTiket`, `jumlahTiket`, dan `namaPembeli` dikelola oleh Parent Composable dengan `rememberSaveable`, serta menggunakan `LaunchedEffect` untuk menangani status validasi dan simulasi pemesanan asynchronous.
